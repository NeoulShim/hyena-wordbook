단어장 연결

동기화 키를 입력하세요. 인증한 브라우저는 다음 방문부터 자동으로 연결됩니다.

변경 충돌

    동시에 수정한 항목에 적용할 값을 선택하세요. 서로 다른 항목의 수정은 자동으로 합쳐집니다.

    데이터 저장 안내

    단어장은 Cloudflare 서버에 하나만 저장됩니다. 같은 동기화 키로 연결한 기기는 동일한 단어장을 사용합니다.

    수정 내용은 자동 저장되며, 다른 기기의 변경 사항은 화면을 열거나 약 15초마다 확인합니다. 오프라인 변경은 브라우저에 보관한 뒤 연결 시 반영합니다.

    인증한 브라우저에는 세션이 유지됩니다. 브라우저 데이터 삭제, 세션 만료 또는 ‘세션 해제’ 후에는 키를 다시 입력해야 합니다.

    발음 듣기는 기기의 일본어 음성을 사용합니다. 온라인 음성만 제공되는 경우 재생 시 안내합니다.
